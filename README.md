# Fall & Faint Detector (ESP32)

[![PlatformIO Test (Native)](https://img.shields.io/badge/Unit_Tests-9%2F9_Passed-success?style=flat-square&logo=cplusplus)](https://platformio.org)
[![Platform: ESP32](https://img.shields.io/badge/Platform-ESP32-blue?style=flat-square&logo=espressif)](https://www.espressif.com/)
[![Framework: Arduino](https://img.shields.io/badge/Framework-Arduino-00979D?style=flat-square&logo=arduino)](https://www.arduino.cc/)

Интеллектуальное носимое устройство на базе **ESP32**, предназначенное для автоматического обнаружения падений и состояний неподвижности (обмороков). Система реализует многоуровневую логику оповещения, включая звонки в экстренные службы и SMS-информирование доверенных лиц с передачей GPS-координат.

---

## 🌟 Ключевые возможности

### 1. Детекция критических событий
*   **3-Axis Impact Detection**: Анализ результирующего вектора ускорения ($|A| = \sqrt{x^2 + y^2 + z^2}$) для точного определения момента удара (порог 2.5G).
*   **Faint Detection (Мониторинг обморока)**: Алгоритм анализа дисперсии (variance) данных акселерометра. Если в течение 5 минут дисперсия остается ниже 0.05, устройство идентифицирует состояние обморока.

### 2. Умная система предупреждения
*   **Pre-alert Phase**: 15-секундный режим «тихой тревоги» перед вызовом служб.
*   **Dynamic Audio Ramping**: Использование ESP32 LEDC (PWM) для плавного нарастания частоты звука от 500 Гц до 2000 Гц.
*   **Manual Cancellation**: Возможность отмены ложного срабатывания коротким нажатием кнопки во время фазы Pre-alert.

### 3. Протокол экстренного оповещения
*   **Sequential Calling**: Две попытки дозвона в экстренные службы (112) с воспроизведением предзаписанного голосового сообщения (TTS).
*   **GPS Integration**: Автоматическое формирование ссылки на Google Maps в экстренном SMS.
*   **SOS Override**: Мгновенная отправка SOS при удержании кнопки более 5 секунд (в обход всех таймеров).

## 🛠 Технический стек

*   **Hardware**: ESP32 (WROOM/WROVER), MPU6050 (IMU), NEO-6M (GPS), SIM800L (GSM), SSD1306 (OLED).
*   **Libraries**:
    *   `NimBLE-Arduino`: Легковесный стек BLE для настройки контактов.
    *   `TinyGSM`: Надежный драйвер для AT-команд SIM800L.
    *   `Adafruit Unified Sensor`: Унифицированный интерфейс датчиков.
    *   `ArduinoFake`: Инструментарий для Unit-тестирования на стороне хоста.

## 🏗 Архитектура прошивки

Проект следует принципам модульности и инкапсуляции:

*   📂 `src/modules/fall_detector`: Обработка векторов ускорения и логика падения.
*   📂 `src/modules/motion_monitor`: Анализ дисперсии и детекция неподвижности.
*   📂 `src/modules/alert_manager`: Управление PWM-звуком и очередью оповещений.
*   📂 `src/modules/comms`: Интеграция GSM, BLE (MyBLEService) и GPS.
*   📂 `src/modules/sensors`: Драйверы-обертки для аппаратной периферии.
*   📄 `src/config.h`: Централизованное управление константами (таймауты, пины, пороги).

## ⚙️ Настройка (config.h)

Все ключевые параметры легко настраиваются в `src/config.h`:
```cpp
#define FALL_THRESHOLD      2.5f    // Чувствительность удара
#define FAINT_TIMEOUT_MS    300000 // Время до детекции обморока (5 мин)
#define PRE_ALERT_DURATION  15000  // Время на отмену (15 сек)
#define BUZZER_FREQ_START   500    // Начальная частота звука
#define BUZZER_FREQ_END     2000   // Финальная частота звука
```
